# Установка

Запустите set_configs.sh:
```bash
bash set_configs.sh
```

**Важно:** этот скрипт заменит ваши конфиги симлинками на этот репозиторий. Существующие реальные конфиги не удаляются, а переименовываются в `<имя>.bak.<timestamp>` рядом в `~/.config`.
